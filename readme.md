# 👾 Gigi's Portfólio

Este é o repositório do meu portfólio pessoal, construído para apresentar meus projetos, habilidades e formas de contato. O design mistura uma estética retrô em pixel art (8-bits) com uma tipografia cursiva elegante, focando em acessibilidade e código limpo.

## Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** Estilização, Flexbox para layout e importação de web fonts (Google Fonts).
* **JavaScript:** (Se você tiver interações, mencione aqui, se não, pode apagar).
* **Figma:** Para a prototipação e design inicial.

---

## Destaques do Projeto

* **Acessibilidade (a11y):** Uso da classe utilitária `.sr-only` e atributos `aria-hidden` para garantir que a estilização das fontes por imagem não prejudique a leitura por leitores de tela.
* **Design Responsivo:** O layout se adapta a diferentes tamanhos de tela.
* **Estilo Único:** Combinação das fontes *Press Start 2P* e *Great Vibes* para criar uma identidade visual marcante.
